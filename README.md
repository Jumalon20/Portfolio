# Abel Jumalon Portfolio Website

A responsive single-page portfolio based on Abel Jumalon's IT Support & Systems resume.

## Files
- `index.html` — website content
- `style.css` — design and responsive styling

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your actual email.
2. Replace the LinkedIn placeholder link with your LinkedIn profile URL.
3. Add a profile photo if desired.
4. Open `index.html` in a browser to preview.
5. Upload both files to GitHub Pages, Netlify, Vercel, or another static hosting service.

The site is intentionally built with plain HTML/CSS/JS so it can be hosted for free without a backend.
